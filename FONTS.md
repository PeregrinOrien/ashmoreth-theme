# Fonts

Ashmoreth embeds subsets of the following fonts as base64 woff2 inside `theme.css`. In the CSS they're renamed to `AshDisplay`, `AshNav`, `AshBody` and `AshMono`.

| CSS name | Font | Author | Licence |
|---|---|---|---|
| AshDisplay | Bodoni Moda SC 2.005 | Owen Earl / indestructible type, https://github.com/indestructible-type/Bodoni | SIL Open Font License 1.1 |
| AshNav | Cinzel 2.000 | Natanael Gama, https://github.com/NDISCOVER/Cinzel | SIL Open Font License 1.1 |
| AshBody (regular, italic, bold) | Old Standard TT 3.000 | Alexey Kryukov | SIL Open Font License 1.1 |
| AshMono | basis33 0.3 | Tristan Grimmer, Manchson | MIT |

The full text of the SIL Open Font License 1.1 is in [OFL.txt](OFL.txt) and at https://openfontlicense.org. The fonts remain under their own licences; the MIT licence in `LICENSE` covers only the theme code.
